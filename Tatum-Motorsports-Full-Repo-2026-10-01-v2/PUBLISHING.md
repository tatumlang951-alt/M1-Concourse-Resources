# Upload and publish

This package contains the complete nine-page website, all 17 active images, styles, JavaScript, and editable Python/JSON source. No build is needed to publish.

1. Extract the ZIP on your computer.
2. Open index.html to preview the actual multi-page website. Keep its folders together.
3. Create a public GitHub repository named motorsports-resources (or use your existing repository).
4. Choose Add file > Upload files. Upload the extracted contents, including the assets and tools folders. Upload the contents, not the ZIP or an enclosing folder. index.html must appear at the repository root.
5. Commit the upload to main.
6. In Settings > Pages, set Source to Deploy from a branch, select main and / (root), and Save.
7. Wait for deployment. Use the live URL displayed in Pages settings.

The separate Tatum-Motorsports-Preview-2026-10-01-Updated.html is an offline, single-file review copy. Download it and open it in a normal browser so its tab navigation runs. You do not need to upload that review copy to GitHub.

Future edits: update the same repository. See README.md for source editing and rebuild instructions.
